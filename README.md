# 第三份阳性报告 · v3.0.3

中文校园 Web ARG。四套独立 HTML 使用真实相对链接往返，分别呈现经典论坛、蓝白后勤、粉白视频镜像与班级网盘。

- `dist/index.html`：争议原帖、历史检索、打印委托、图像比对与陈叙说明。
- `dist/canteen/index.html`：一卡通、名册/流水/点名/签收核对、设备归档、采购和汇总。
- `dist/video/index.html`：四张本地SVG切片构成轻量播放器，支持时间戳、推焦、水印及定时弹幕；没有MP4。
- `dist/pan/index.html`：多账号资料柜、素材提取、沈栀授权与草稿、真解密Excel及处理意见。

调查从宿舍嫌隙与图纸来源，进入医疗漏列与后勤推诿，再通过五组互证形成审计闭环。不按19章逐页提交解锁；医疗、到场与审计支线可交错取证。

公共 `dist/state-sync.js` 统一读写 `localStorage.qinghe_arg_save`，监听跨标签storage事件、合并独立发现并保留连线重核。四站共用随身错题本，支持1.5秒自动收录、点击字段收录、选卡连线、来源回查、手记和渐进提示。

首次升级只读迁移旧存档与手记。原案已核实事实、账号、副本、草稿、工作表和审计关系可继续使用。旧纯逻辑接口与渲染模块保留回归兼容；四个生产入口不再加载旧伪桌面或章节运行时。站点跳转收在随身调查本的渐进书签内，仍使用真实相对链接。

## 开发与部署

无安装依赖、无后端。GitHub Pages发布目录为 `dist`，全部路径相对，支持项目站点子目录。WebCrypto需HTTPS，GitHub Pages已满足。

```sh
npm run check
npm run build:frames  # 需要重建静态视频切片时运行
```

推送main后由GitHub Actions校验并发布。无需API密钥、真实学生账号或外部视频服务。

拓扑、事实依赖、状态协议和模块接口见 [系统重构说明（含剧透）](docs/SYSTEM-REBUILD.md)。旧版本设计记录保留于docs，不进入游戏搜索。

故事、人物和文书均为虚构；医学记录用于核对可靠性及收文时间，不用于确定谁传染谁。现实诊疗与用药应由医生确认。

## v3.0.1 交互细节

- 四站共用青禾内网顶栏，绿点与8ms为游戏内模拟状态。
- 调查本点击外部收起；新收录线索触发短暂呼吸和红点，打开调查本后消除提醒。原有手记会在收起时保存。
- 视频支持空格播放/暂停、左右方向键和进度条两侧按钮各移动3秒。输入时和调查本展开时不响应全局快捷键。
- 提取码错误保留输入并显示红色提示和抖动，重新输入即清除错误状态。系统减少动态效果偏好会停用呼吸和抖动，保留静态提醒。

存档键与谜题规则沿用v3.0，无需重开。
