# v2.1 内网界面改版

本次只更新展示与交互层，保留十九章、答案、账号口令、证据条件、两结局及原有存档键。

## 界面层次

- **桌面与浏览器**：中性灰标题栏、细边框地址栏、紫色导航，保留桌面窗口的最小化、还原和任务栏。沿用已有校园与宿舍生图。
- **经典论坛**：2015—2018年BBS风格的主题栅格和楼层结构。左侧作者、方形头像、等级和用户组，右侧正文、签名、点赞/举报和来源。公告红签、置顶与精华黄签；固定版权文字“青禾高级中学网络信息中心 © 2018 版权所有”。
- **复印报告**：生图模型生成空白复印纸，代码排版确保标题、日期、单位、条码、图线和红章清楚可读。主线四张表为C14，DPM计数与本虚构医院参考界值配套；R07的C13/DOB材料保持原指标。A/C除日期外完全一致，保留相同折痕与蓝圈缺口。
- **线索本**：右侧可弹出的原生对话框抽屉，方格底纸、圆珠笔改写、纸胶带与便签。收藏证据与已核对证据区别显示；只有真实推理/连线中核对的材料标黄。手记、划线、点赞等写入独立展示偏好，不改变答案或关卡。
- **证据板**：软木底与黄色纸片，沿用手动选卡、判断关系和连线。原有文字关系列表继续保留。

## 实际交互

| 操作 | 行为 | 边界 |
| --- | --- | --- |
| 进入私信、账号、班级资料夹、邮箱、附件系统 | 约300ms连接提示和旋转图标 | 相同路由刷新不额外等待；后续跳转取消旧回调，避免过期页面覆盖 |
| 阅读私信 | 最后一条对方消息短暂打字呈现 | 完整内容同时对辅助技术可读；最长约1.2秒 |
| 查看撤回留存 | 引用由模糊到清晰，红色撤回说明 | Q0325-07在实际撤回之前不会提前标成已撤回；不从后台恢复未经授权内容 |
| 后段完成关键质疑 | 顶部约100ms扫描线、短暂连接恢复提示 | 单个事件只触发一次，至少间隔30秒；不挡输入、不弹阻塞式假报错 |
| 点赞/举报 | 本机标记、可取消赞、举报回执 | 明示论坛存档副本，不真实联系版主或发送消息 |
| 翻线索本 | 侧签、手机底栏、阅读器内按钮、Alt+N | 支持Esc合上与焦点返回；阅读器内可叠开，不改变当前表单 |
| 手机返回目录 | 底栏直接打开当前已解锁章节目录 | 不提前列出未来章节；正文预留底栏及安全区域，不盖住提交按钮 |

界面设置可关闭连接等待和氛围动效。系统“减少动态效果”开启时禁止模糊、扫描线和抖动。所有反馈有常规文字；不以声音或闪动作为唯一线索。
