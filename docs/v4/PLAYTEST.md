# P1 候选样章盲测包（无解答）

这是《第三份阳性报告》v4.0 的首段候选样章，预计约30分钟，实际时长有待测试。旧版进度与新版分开，试玩不会把旧版解答套到新故事。

## 给测试者

1. 从候选版论坛首页开始，不打开源码、测试脚本或设计者文档。
2. 自由读帖、搜索和访问正文中的站点。调查本可回查材料、记手记和提出自己的判断。
3. 读附件超过1.5秒会自动归档。归档不代表已经推理正确。
4. 卡住时可主动打开三级提示。请记录何时用了哪一级。
5. 本段目标是在调查本中整理一份阶段说明。不是找出感染源，也不要求阅读任何私密信件。
6. 可随时停止，导出试玩记录交给安排测试的人。不上传真实医疗、账号或个人信息。

| 字段 | 记录 |

| 匿名编号 / 日期 / 设备 / 浏览器 | |
| 开始 / 暂停 / 结束 / 净时长 | |

| 你现在认为哪些事实已证实，哪些不能确定 | |

| 人物可信度 / 网页真实感 / 调查参与感（各1—5） | |
| 截图或操作问题（可选） | |

## 主持者检查

不口头暗示下一站或答案，必要时让测试者自行打开三级提示。记录观察与解释，区分“没找到材料”和“找到但没理解”。六人的记录齐全并复核阻断点后，才能判定P1通过；这里没有预填通过结果。P2/P4完整作品测试另设8人，不能拿本轮短样章时长推断完整作品时长。
