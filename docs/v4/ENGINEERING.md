# 工程协议与里程碑

## 交付边界

`dist/v4/index.html`、`canteen/index.html`、`video/index.html`、`pan/index.html` 四个独立页面。静态相对链接，无路由服务要求，部署到 GitHub Pages 的项目路径也可工作。v3.2入口、旧逻辑和111项原有检查保留。P1候选不替换生产根入口；6人真实盲测通过后才进入P2。

## 活动存档

唯一活动键仍为 `qinghe_arg_save`。外层保留version3旧投影，使旧站可继续读取；`campaigns['qinghe-2025-v4']`是隔离的新调查，外层`save_schema:4`、`active_campaign`标记封套。旧投影不会给新版解锁。原始旧字符串先写为不可变归档；新存档通过校验、备份后再覆盖活动键。归档失败则停止持久迁移，仍允许内存试玩且明确提示。

IndexedDB只保留恢复快照，不是活动事实源。新标签启动时先读活动键；只有键缺少新版封套/有效数据时才从快照恢复。旧标签剥离未知字段时，新标签监听storage补回；新标签全关后旧标签覆盖时，下次启动从恢复快照补回。更高版本/非法导入不悄悄降级。结构化字段采用逻辑时钟与actor确定性合并；站点/材料为并集，假设与手记为LWW，可撤回而不丢失原件。

持久层失败必须可见，导出包含原始旧档与新战役；恢复导入先解析、验证、再合并，错误内容不得擦除存档。IndexedDB不可用时以附带校验的localStorage恢复快照兜底；该键同样不是活动存档。所有写入须受同源锁协调（Web Locks可用时），并发合并不得丢材料。

## 验证器

材料有source/copy_of，来源去重；结论校验语义立场、独立来源和可替代证明组合，而不是固定行号与材料全收集率。观察与结论分开，自动收录不解题。P1的高风险断言涵盖：副本不能双计，普通模板特征不能识别同源，返校不能证明改图，阴性不能推导传播来源。

## 发布与测试

逻辑回归、静态链接/资源/事实校验、Chromium实际交互与截图在内部完成。Firefox/WebKit若本地缺少运行时必须在CI实跑，不能把配置文件当成通过记录。真人盲测结果由真实测试者填写，禁止生成。记录首屏传输、窄屏和200%缩放；测试视频字幕/逐图替代、跨标签、旧标签覆盖、导出恢复、错误配对与改判。

P1六人测试：误会→跨站→核实→改判，收集卡点和两级提示使用。不以内部用答案脚本取代30分钟体验。P4最终8人测试及3—5小时、理解度和评分指标，全部按批准方案执行。当前未达P4，不标正式v4.0。
